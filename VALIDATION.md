# Version 1.7 validation

Model tests: 34 passed locally and on the Mac CI runner, including deterministic, bounded, quality-nested galaxy sectors; black-hole radii and landing rejection; MOLA heights for Olympus Mons, Hellas and northern plains; Earth mountain/ocean locations; terrain boundaries matching the globe mesh; previous orbital, persistence and updater checks. The renderer build succeeds.

The local execution environment currently aborts Electron and headless Chrome before they open the renderer; LaunchServices reports an executable launch error. The Intel app bundle builds and passes code-signature verification. Local DMG creation fails with `hdiutil: Device not configured`. These environment failures do not establish visual correctness.

The [final source graphics run](https://github.com/gtts-ux/cosmosEngine/actions/runs/39880105826) passed on an Apple Silicon Mac runner. All six regression groups passed with no renderer, shader or streaming errors: four solid surfaces; black-hole rendering and landing rejection; all five galaxy regions; 10/20/50 ly streaming ranges; selecting without moving and generated-system travel; bounded system residency after repeated visits. The catalog also retains usable height on the compact test display. Screenshots and the report are retained as workflow artifacts. Screenshots were reviewed for terrain masking, galaxy haze, black-hole visibility and compact HUD layout.

The release workflow repeats source validation, builds both Intel and Apple Silicon DMGs, verifies each disk image with hdiutil, and runs the graphics suite against the packaged Apple Silicon app before allowing publication. An Intel runtime check for this version is unavailable because of the local launch failure above. Packaging alone does not establish Intel runtime performance.

The [v1.7.0 release run](https://github.com/gtts-ux/cosmosEngine/actions/runs/39880348493) completed successfully: source validation, both DMG builds and verification, all six packaged Apple Silicon graphics groups, and publication. The packaged report records zero errors and 784 resident bodies after repeated system visits. Both public installer URLs and the checksums URL returned HTTP 200. The locally downloaded Intel DMG matches the published SHA-256 `2e16243a642373b79c267e6f4b9d3ace0fed0d8d9dfd4e5f093183063baaa8b3`. Downloads: [v1.7.0](https://github.com/gtts-ux/cosmosEngine/releases/tag/v1.7.0).

Known limits: galaxy structure and unresolved stars are procedural; local detailed stars are generated only inside the configured radius. Galaxy overview points represent distant aggregate structure. Earth heights are approximate; Mars elevations are measured at 0.25° resolution. Surface microdetail and accretion disks are illustrative. No new FPS claim is made without a completed runtime benchmark.
